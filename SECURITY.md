# Security policy

RepoGauntlet v0.1 is an authoring and calibration tool, not a hardened hosted code-execution service. Do not use its local runner for untrusted submissions.

Report a suspected vulnerability privately through GitHub Security Advisories. Include the affected version, reproduction, impact, and any suggested mitigation. Please do not open a public issue before a fix is available.

The supported release line is `0.1.x`. See [the threat model](./docs/threat-model.md) for boundaries and known limitations.
